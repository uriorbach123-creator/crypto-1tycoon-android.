איך לבנות APK כשיש לך רק טלפון Android
=======================================

הדרך המומלצת: לבנות בענן דרך GitHub Actions. לא צריך מחשב.

1. הורד את קובץ ZIP של הפרויקט לטלפון וחלץ אותו באמצעות "הקבצים שלי" / Files.
2. פתח חשבון GitHub או התחבר: https://github.com/
3. בדפדפן בטלפון פתח https://github.com/new וצור Repository חדש בשם crypto-tycoon-android.
   מומלץ לבחור Private.
4. פתח את ה-Repository החדש > Add file > Upload files.
5. העלה את כל הקבצים והתיקיות שבתוך תיקיית crypto-tycoon-android שחילצת (לא להעלות את תיקיית-האב עצמה).
   חשוב: צריך לשמר את מבנה התיקיות, כולל .github/workflows/build-apk.yml.
   אם ממשק הטלפון לא מאפשר העלאת תיקיות/קבצים מוסתרים, אפשר להפעיל "אתר למחשב" בדפדפן או להשתמש באפליקציית GitHub/כלי Git.
6. אשר Commit changes.
7. היכנס ללשונית Actions של ה-Repository. בחר "Build Crypto Tycoon APK" ולחץ Run workflow אם הוא לא התחיל לבד.
8. המתן לסיום הריצה. פתח את הריצה הירוקה, גלול ל-Artifacts והורד crypto-tycoon-debug-apk.
9. חלץ את ה-ZIP שהורדת. בפנים נמצא app-debug.apk. פתח אותו ואשר התקנה ממקור זה אם Android מבקש.

AdMob:
------
הפרויקט משתמש כרגע במזהי TEST הרשמיים של Google. זה מאפשר לבדוק את מסך הפרסומת בלי להציג מודעות אמיתיות לחשבון שלך.
כדי להציג פרסומות אמיתיות, צריך קודם:
- ליצור אפליקציית Android בחשבון AdMob: https://admob.google.com/
- ליצור יחידת מודעה מסוג Rewarded.
- להחליף את מזהה האפליקציה בקובץ app/src/main/AndroidManifest.xml
- להחליף את REWARDED_AD_UNIT_ID בקובץ app/src/main/java/com/example/cryptotycoon/MainActivity.java
- לבצע build חדש בענן ולהתקין את ה-APK החדש.

חשוב מאוד:
- אל תלחץ על מודעות אמיתיות של עצמך. השתמש במזהי TEST במהלך הפיתוח.
- מודעה אמיתית לא מובטחת בכל לחיצה; לפעמים אין מודעה זמינה.
- אין לפרסם או להפיץ את האפליקציה לפני בדיקת מדיניות AdMob, מדיניות פרטיות והסכמות נדרשות.
- קובץ Debug APK אינו קובץ חתום להפצה ב-Google Play. להפצה צריך ליצור חתימת Release/AAB ולשמור את מפתח החתימה במקום בטוח.
